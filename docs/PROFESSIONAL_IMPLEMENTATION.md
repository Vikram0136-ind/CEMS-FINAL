## 🚀 **How to Use**

### **Start the App**
```bash
cd CEMS_AGC_GitHub_Ready
.venv\Scripts\activate
python app.py
```

### **Access Different Portals**

**Student Portal** (Login as):
- Email: `student@agc.local`
- Password: `Student@123`
- Navbar → Dashboard → Browse Events → Register → View Tickets

**Organizer Portal** (Login as):
- Email: `organizer@agc.local`
- Password: `Organizer@123`
- Navbar → Dashboard → Create Event → Manage Registrations → Check-in

**Admin Portal** (Login as):
- Email: `admin@agc.local`
- Password: `Admin@123`
- Navbar → Dashboard → Manage Events → Approve Events → View Reports

### **Test All Features**

1. **Browse Events**
   - Click category cards on homepage
   - Use filters on events page
   - View full event details
   - See all 35+ events

2. **Register for Events**
   - Click "Register Now" on event details
   - Complete registration form
   - Get instant ticket with QR code
   - See in "My Tickets"

3. **Check-in (Organizer)**
   - Go to Check-in page
   - Enter ticket code or scan QR
   - Mark attendance in real-time

4. **Admin Functions**
   - Manage users (block/unblock)
   - Approve pending events
   - View all registrations
   - Generate reports
